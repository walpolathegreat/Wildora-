# Wildora

Wildora is a dependency-light, cinematic nature and wildlife journal built with semantic HTML, modern CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly for a quick preview, or serve the folder through a local static server. For example, with Python installed:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before launch

- Replace `your-production-domain.example` in `index.html`, `robots.txt`, and `sitemap.xml`.
- Replace the `hello@replace-this-domain.example` contact email.
- Replace the Unsplash demo images and Coverr demo film with media you own or have licensed. Keep descriptive alt text and update the captions.
- Connect the newsletter form in `script.js` to a provider such as Mailchimp or Buttondown before treating subscriptions as active.
- Replace the starter privacy and terms pages with reviewed policy text.
- Add real social profile URLs in the footer.

## Free deployment

The project is static and can be published with GitHub Pages, Netlify, Cloudflare Pages, or another static host. On GitHub Pages, push the repository, open Settings → Pages, select the main branch and root folder, save, and test the generated URL. Hosting settings can change, so check the provider's current documentation at deployment time.
